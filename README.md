# スラ読オン読

入試英文のスラッシュリーディング・音読ノート。ブラウザだけで動きます（PDFの読み取り・OCRは端末内で処理）。

- アプリ: https://sesesesesereko.github.io/suradoku/
- AIの機能は「AIの設定」で Gemini（自分の API キー）を選んで使います。キーはその端末のブラウザにだけ保存されます。

同梱ライブラリとデータのライセンスは `vendor/` 内の各 LICENSE ファイルを参照してください（pdf.js: Apache-2.0、Tesseract.js: Apache-2.0、compromise: MIT、辞書データ: CC BY-SA 4.0）。
